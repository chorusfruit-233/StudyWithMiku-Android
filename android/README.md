# Study With Miku · Android 1.2.5

原作：[shshouse/StudyWithMiku](https://github.com/shshouse/StudyWithMiku)，基线提交 `159db717f02debf71a5138764ed8e068f4577f94`。原生 Kotlin、Compose、Media3；Material 3 Expressive 主题、动态形状按钮和花瓣计时进度。支持 Android 8.0（API 26）以上，target API 35。

包名（applicationId 与 namespace）：`io.github.chorusfruit233.studywithmiku`。新包名作为独立应用安装，可与旧版共存；本机资料不自动迁移，可登录同一账号恢复云端学习资料。

启动图标使用 `mipmap`：API 26 起为独立前景／背景的 AdaptiveIcon，API 33 起增加 monochrome。前景与单色图案使用 108 dp 画布，缩放至中心 66 dp 安全区域；单色版本眼睛与笑脸使用透明镂空，支持启动器根据壁纸着色。普通与 roundIcon 均采用自适应资源，保留旧矢量图作默认回退。

网页拖拽浮窗适配为手机的聊天底部面板，可在计时与音乐播放时打开。音乐额外支持通知栏／锁屏控制、耳机拔出暂停、本地导入、收藏与自建歌单。聊天连接仅在应用前台保持；后台媒体与计时由各自可见前台服务维持。

## 使用与接口

在“社区 → 账号”打开官方登录页。登录地址沿用 `https://mikumod.com/login?redirect=study&callback=https%3A%2F%2Fstudy.mikumod.com`，内置 WebView 捕获原站根路径的 `#study_token` 回调。仅在 HTTPS 官方回调与服务端认证均通过后保存凭据。无 JavaScript 桥接，无后端修改，无密码读取；登录页禁止截图并正常校验 TLS。若身份提供方限制内置 WebView，此流程会受其限制；外部浏览器不会自动把原站 HTTPS 回调交回此应用，当前没有未经后端支持的替代 OAuth 回调。

账号 API 为 `https://mikumod.com/api/study/data`、`/calendar` 与 `/profiles`。云端学习时长使用秒，本机使用毫秒，设置时长使用分钟。保留未知云端字段，日历按日期拆分，合并采用每日最大值而非相加。云端读取失败或数据格式异常会阻止上传。首次合并前提供使用云端／上传本地／合并选择；切换账号和退出登录分别恢复账号／访客档案。启用自动同步后，静止时延迟两秒同步，计时中每分钟同步。云同步只涵盖原作支持的资料；音乐导入、收藏、播放队列、主题等原生扩展保存在本机。

选择云端时重新 GET 两份资料，展示进度，保存后才关闭弹窗；失败保留原资料和选择框。分别保存云端原始 JSON 与本地应用后的快照，跨重启判断资料是否真正变化，避免默认设置补齐、数字格式、JSON 字段顺序或跨午夜造成重复弹窗。该基线跟随各账号备份与恢复。已有 1.2.1 档案可使用保存的云端快照判断云端未变化。1.2.3 对两端使用同一套有效资料比较：补齐原作默认值、处理空日历记录与数值精度，云端跨天不会制造新冲突；访客资料与账号资料一致时直接接入同步。时长按毫秒比较，真实秒数、待办、每日记录和设置差异仍需选择；选择框显示秒数与差异类别。保留待办、计划、倒数日及日记录中的未知字段。

聊天连接 `wss://online.study.mikugame.cc/ws`，使用原作 `auth`、`username`、`ping`、`load_history`、`chat` JSON 协议。登录后才能发言；昵称不能替代服务端认证。退出登录后重新建立匿名连接。

音乐源默认 `https://api.qijieya.cn/meting/`，默认网易云歌单 `17543418420`，音质 `2000`；推荐歌单与平台保持原作数据。平台 HTTP／HTTPS CDN、重定向和资源可用性沿用原作，仍校验 TLS。网络列表缓存不等于歌曲下载。

## 构建与验证

```sh
./gradlew assembleDebug testDebugUnitTest lintDebug
```

需要 JDK 17、SDK 35；首次构建下载依赖。输出 `app/build/outputs/apk/debug/app-debug.apk`。调试签名每次 CI 生成，工程无签名私钥。Expressive API 使用明确固定的 `material3:1.4.0-alpha18`。

协议、HTTP 错误、账号凭据校验、云合并、分享和计时单元测试使用本地测试服务器。真实账号登录、发言、云端写入与跨设备同步须在用户手机上验收；当前无测试账号。详细边界见 [VALIDATION.md](VALIDATION.md)。

有设备或模拟器时，可运行 `./gradlew connectedDebugAndroidTest` 执行离线聊天手势回归测试；CI 会编译该测试包，实际设备执行结果记录在验证文档中。
