# Study With Miku · Android 工程说明

非官方 Android 移植。原作：[shshouse/StudyWithMiku](https://github.com/shshouse/StudyWithMiku)，功能基线更新至提交 `a3c4e5e0d4be48b2e21662ac85ff6022f8aa926d`，覆盖原作 2026-10-09 更新记录及 10 月 10 日的歌单管理后续调整。原生 Kotlin、Compose、Media3；Material 3 Expressive 主题、动态形状按钮和花瓣计时进度。支持 Android 8.0（API 26）以上，target API 35。

仓库和已发布版本公开；安装请使用 [最新正式 Release](https://github.com/chorusfruit-233/StudyWithMiku-Android/releases/latest)。用户说明见 [根目录 README](../README.md)，更新记录见 [CHANGELOG.md](../CHANGELOG.md)。本页说明功能映射、接口与原生适配。

包名（applicationId 与 namespace）：`io.github.chorusfruit233.studywithmiku`。新包名作为独立应用安装，可与旧版共存；本机资料不自动迁移，可登录同一账号恢复云端学习资料。

启动图标使用 `mipmap`：API 26 起为独立前景／背景的 AdaptiveIcon，API 33 起增加 monochrome。前景与单色图案使用 108 dp 画布，缩放至中心 66 dp 安全区域；单色版本眼睛与笑脸使用透明镂空，支持启动器根据壁纸着色。普通与 roundIcon 均采用自适应资源，保留旧矢量图作默认回退。

专注页聊天面板会消耗消息列表底部未使用的上滑距离与惯性，避免消息到底后带动面板回弹；向下滚动与拖动关闭仍沿用原生交互。

网页拖拽浮窗适配为手机的聊天底部面板，可在计时与音乐播放时打开。音乐额外支持通知栏／锁屏控制、耳机拔出暂停、本地导入、收藏与自建歌单。聊天连接仅在应用前台保持；后台媒体与计时由各自可见前台服务维持。

计时服务自动持有有超时的 `PARTIAL_WAKE_LOCK`，按运行状态续租，暂停或结束后释放；音乐播放由 Media3 管理唤醒锁。`WAKE_LOCK` 是安装时授予的普通权限，不通过运行时权限弹窗申请。1.2.9 在首次开始计时时，使用 `ACTION_REQUEST_IGNORE_BATTERY_OPTIMIZATIONS` 申请系统电池优化豁免；拒绝后不反复自动提示，手动申请入口保留在“设置 → 后台运行”。返回系统设置时重新读取 `isIgnoringBatteryOptimizations`，不把打开页面视为授权成功。

授权后仍提示进入应用信息的电池／后台耗电管理，将应用设为“无限制”；厂商设置需要用户在系统界面确认。直接授权页不可用时回退到优化列表、应用信息或系统设置。自动申请与提示记录保存在独立的本机 SharedPreferences，不进入学习云同步。

## 使用与接口

在“社区 → 账号”打开官方登录页。登录地址沿用 `https://mikumod.com/login?redirect=study&callback=https%3A%2F%2Fstudy.mikumod.com`，内置 WebView 捕获原站根路径的 `#study_token` 回调。仅在 HTTPS 官方回调与服务端认证均通过后保存凭据。无 JavaScript 桥接，无后端修改，无密码读取；登录页禁止截图并正常校验 TLS。若身份提供方限制内置 WebView，此流程会受其限制；外部浏览器不会自动把原站 HTTPS 回调交回此应用，当前没有未经后端支持的替代 OAuth 回调。

账号 API 为 `https://mikumod.com/api/study/data`、`/calendar` 与 `/profiles`。云端学习时长使用秒，本机使用毫秒，设置时长使用分钟。保留未知云端字段，日历按日期拆分，合并采用每日最大值而非相加。云端读取失败或数据格式异常会阻止上传。首次合并前提供使用云端／上传本地／合并选择；切换账号和退出登录分别恢复账号／访客档案。启用自动同步后，静止时延迟两秒同步，计时中每分钟同步。云同步只涵盖原作支持的资料；音乐导入、收藏、播放队列、主题等原生扩展保存在本机。

1.2.10 合并时，缺失或非有限的数值字段采用有限默认值，单端日期保留已有学习值；相同记录 ID 保留本机编辑及双方附加字段。上传仅发送原作支持的顶层字段：学习资料 `stats/todos/settings`，日历 `dailyLog/plans`；顶层档案附加信息继续在本机保存，记录内部字段保留。两份文档在首个写入前都完成结构、数值和 JSON 编码检查。账号 API 使用 Bearer、原作 `application/json` 与 UTF-8，不附带登录 WebView Cookie 或共享 CookieJar；错误信息区分读取／上传及学习资料／日历。

选择云端时重新 GET 两份资料，展示进度，保存后才关闭弹窗；失败保留原资料和选择框。分别保存云端原始 JSON 与本地应用后的快照，跨重启判断资料是否真正变化，避免默认设置补齐、数字格式、JSON 字段顺序或跨午夜造成重复弹窗。该基线跟随各账号备份与恢复。已有 1.2.1 档案可使用保存的云端快照判断云端未变化。1.2.3 对两端使用同一套有效资料比较：补齐原作默认值、处理空日历记录与数值精度，云端跨天不会制造新冲突；访客资料与账号资料一致时直接接入同步。时长按毫秒比较，真实秒数、待办、每日记录和设置差异仍需选择；选择框显示秒数与差异类别。保留待办、计划、倒数日及日记录中的未知字段。

聊天连接 `wss://online.study.mikugame.cc/ws`，使用原作 `auth`、`username`、`ping`、`load_history`、`chat` JSON 协议。登录后才能发言；昵称不能替代服务端认证。退出登录后重新建立匿名连接。

回复使用原作 `[reply:消息id]正文` 文本协议，无需额外后端接口。显示引用用户名和摘要，引用原消息未加载时保留正文并提示加载历史；回复正文中的表情、歌曲与倒数日仍按原卡片类型显示。发送成功后清除回复目标，失败保留输入与目标，切换账号会清除回复目标。500 字符上限包含回复前缀。

音乐源默认 `https://api.qijieya.cn/meting/`，默认网易云歌单 `17543418420`，音质 `2000`；推荐歌单与平台保持原作数据。平台 HTTP／HTTPS CDN、重定向和资源可用性沿用原作，仍校验 TLS。网络列表缓存不等于歌曲下载。

“我的网络歌单”与 Android 本地歌曲组成的歌单分开保存。自定义歌单只有曲目加载成功后才进入列表；名称通过原作 `https://online.study.mikugame.cc/playlist-name?platform=…&id=…` 获取，最多等待四秒，失败显示 `ID:歌单id`。该请求不发送账号凭据。保存键为平台与歌单 ID，同 ID 在网易云和 QQ 中可分别保留；该列表只保存在本机，不进入学习云同步。

## 构建与验证

```sh
cd android
./gradlew assembleDebug testDebugUnitTest lintDebug
```

从仓库根目录执行以上命令，需要 JDK 17、Android SDK 35 和 Build Tools 35.0.0；首次构建下载依赖。输出 `android/app/build/outputs/apk/debug/app-debug.apk`。Debug 构建无需正式密钥，临时签名由构建环境生成。正式 Release 包使用固定 StudyWithMiku 证书；环境变量提供签名参数，公开源码不包含签名私钥或密码，缺少参数时 Release 打包明确失败。详见 [RELEASING.md](RELEASING.md)。Expressive API 使用明确固定的 `material3:1.4.0-alpha18`。

`Android app` 工作流在源码变更时构建 Debug，并执行单元测试、Lint 与 Android 35 设备回归；Debug 附件保留在未公开草稿中。`Android signed release` 工作流通过版本标签或手动运行构建正式包，先生成草稿，维护者确认后公开发布。已发布版本不会被工作流覆盖。

协议、HTTP 错误、账号凭据校验、云合并、分享和计时单元测试使用本地测试服务器。真实账号登录、发言、云端写入与跨设备同步须在用户手机上验收；当前无测试账号。详细边界见 [VALIDATION.md](VALIDATION.md)。

有设备或模拟器时，可运行 `./gradlew connectedDebugAndroidTest` 执行离线聊天手势回归测试；CI 会在 Android 35 模拟器运行聊天手势、同步选择、任务操作与持久化回归，执行结果记录在验证文档中。

## 安装包组成

1.2.7 正式 APK 约 129 MB：11 首内置 MP3 约 65 MB、3 段 MP4 约 44 MB、DEX 代码约 15 MB，其余为图片、表情、资源与元数据。内置音视频约占 84%，均保留原始编码。

该版本 `isMinifyEnabled=false`，尚未开启 R8 和资源裁剪；`mp3`、`mp4` 以不再 ZIP 压缩的方式打包。网络歌单本身只保存配置和列表，不把所有推荐歌曲打入 APK。
